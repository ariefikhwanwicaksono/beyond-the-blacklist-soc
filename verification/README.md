# Verification scripts

These scripts back specific claims in the paper about dataset quality and malware identity. They are
separate from the four experiment folders. Each script states the claim it checks and the expected output
in its header.

| Script | Claim checked | Input (see root README for sources) | Re-run 2026-11-03 |
|---|---|---|---|
| `verify_tinba_dga.py` | The 1,000 `.xyz` domains queried by the "tinba" host are generated by the published Tinba DGA (unique seed parameters 75/106, 1000/1000 in order) | `zeek_out/tinba/dns.log` | not re-run here (see note) |
| `cert_sha1.zeek` + `verify_dridex_sslbl.sh` | 3 of the 5 TLS certificates in the dridex capture are listed by abuse.ch SSLBL as "Dridex C&C" | `dridex.pcap` | reproduced |
| `inspect_zeus_x0proto.py` | The USTC-TFC2016 "Zeus" capture's dominant C2 is the plaintext x0Proto RAT protocol, not Zeus | `zeus_dedup.pcap` (or `zeus.pcap`) | reproduced |
| `capture_integrity_checks.sh` | CTU-Normal-32/33 are not truncated: no truncated_* events, 0% capture loss, Zeek packets/IP bytes identical to Stratosphere's Argus flows | Zeek output + Stratosphere `.binetflow` | reproduced |
| `ctu13_extract_normal_hosts.sh` + `ctu13_zeek_vs_argus.py` | CTU-13 scenario 42 is unusable: in its 54-byte-truncated pcap Zeek parses only 4.6% of the normal hosts' TCP packets (86.3% of TCP flows have zero packets), while UDP matches | Zeek `conn.log` of the truncated pcap + `capture20110810.binetflow` | reproduced |

**Note on `verify_tinba_dga.py`.** The reference DGA is J. Bader's `tinba/dga.py`
(github.com/baderj/domain_generation_algorithms, GPL-2.0). To keep this MIT-licensed repository free of
GPL code, the script downloads that file at run time from a pinned commit (`6ab108e9`) and calls its
`dga()` function unmodified.

The original check (2026-10-20) used an inline re-implementation of the same loop and found the unique
parameters (75, 106) with 1000/1000 domains in order. This download-based version has not yet been
executed by the authors.

Python scripts need `pandas`/`numpy`; the shell scripts need `zeek`, `tcpdump`, `awk` and `curl`.
